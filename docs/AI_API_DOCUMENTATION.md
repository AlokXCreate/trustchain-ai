# TrustChain AI — AI Document Intelligence API Reference

Base URL: `http://localhost:8000/api/v1/ai`

---

## Endpoints

### 1. Analyze Document
- **Method**: `POST /analyze/{document_id}`
- **Description**: Triggers full 12-stage AI/ML analysis on an uploaded or demo document.
- **Response**: Full analysis dossier, OCR blocks, structured fields, risk assessment, and report ID.

### 2. Get Analysis Results
- **Method**: `GET /results/{document_id}`
- **Description**: Retrieves cached multi-modal analysis results.

### 3. Get Verification Report (JSON)
- **Method**: `GET /report/{report_id}`
- **Description**: Returns validated structured verification report.

### 4. Download Verification Dossier (PDF)
- **Method**: `GET /report/{report_id}/pdf`
- **Description**: Downloads official, audit-ready PDF report generated by ReportLab.

### 5. Export Verification Dossier (JSON)
- **Method**: `GET /report/{report_id}/json`
- **Description**: Exports full machine-readable verification report.

### 6. Get Analysis Status
- **Method**: `GET /status/{document_id}`
- **Description**: Returns processing state (`idle`, `processing`, `completed`).

### 7. Re-analyze Document
- **Method**: `POST /reanalyze/{document_id}`
- **Description**: Invalidates cache and re-runs fresh AI multi-modal inference.

### 8. Visual Overlays
- **Method**: `GET /visualizations/{document_id}`
- **Description**: Returns OCR bounding boxes, tamper boxes, and base64 ELA preview.

### 9. Document Findings
- **Method**: `GET /findings/{document_id}`
- **Description**: Returns list of anomaly, consistency, and forensic findings.

### 10. Submit User Feedback
- **Method**: `POST /feedback/{report_id}`
- **Payload**:
  ```json
  {
    "finding_id": "ocr_correction_holder_name",
    "feedback_type": "ocr_correction",
    "field_name": "holder_name",
    "corrected_value": "Alex Mercer",
    "comment": "User corrected extracted name"
  }
  ```

### 11. Model Status
- **Method**: `GET /models/status`
- **Description**: Returns active model versions, runtime framework, and inference latency.

### 12. Model Metrics
- **Method**: `GET /models/metrics`
- **Description**: Returns genuine evaluation metrics (accuracy, precision, recall, F1, confusion matrix).
